# The Ramp

夜间环坡试车。开车冲上环坡，离地后用推进器飞行、翻转，再放平落地。

车身使用 [Tesla Roadster 2020](https://sketchfab.com/3d-models/tesla-roadster-2020-1fbf29e297bd4a17ac39a00a378441d8) by metarex.4d，CC BY 4.0。作者不为此游戏背书。涂装改成了演示片里的银色。

```bash
npm install
npm run dev
```

桌面用 W/S 控制油门（空中改为俯仰），A/D 转向（空中改为横滚），空格推进，F 翻转，R 重置。触屏会显示摇杆和按键。
